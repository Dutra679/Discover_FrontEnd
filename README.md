# DevLinks

Agregador de links baseado no projeto DevLinks do curso [Discover da Rocketseat](https://www.rocketseat.com.br/discover).

## Desenvolvimento

Implementação desenvolvida por Codex, com assistência de IA, a pedido de Dutra. Os commits registram mudanças reais realizadas neste projeto, organizadas conforme os tópicos do curso. As datas e a autoria dos commits não são alteradas para simular participação anterior.

## Etapas

1. Estrutura HTML e configuração do projeto.
2. CSS, fundo e perfil.
3. Lista de links, Flexbox e rodapé.
4. Variáveis CSS e botão para os temas.
5. JavaScript para alternar tema e avatar.
6. Responsividade, animações e documentação.

## Executar

Abra `index.html` no navegador. Não há dependências nem etapa de build.
